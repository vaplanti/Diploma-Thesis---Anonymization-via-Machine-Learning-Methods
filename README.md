# Diploma-Thesis---Anonymization-via-Machine-Learning-Methods
Files pertaining to user's diploma thesis.

The code is written in Python via Jupyter Notebook. The csv files are datasets created for the purposes of this project. They consist of transcripts of TedTalks, the Wolf359 science fiction podcast, and the comedy podcast My Brother, My Brother and Me. They have been broken down by sentence and categorised on whether they contain private information such as names or dates.
